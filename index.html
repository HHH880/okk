Study notes

Getting ready for computer science

A friendly overview of what the degree usually covers and how to make the most of it.

What is computer science?

It is the study of how computers work and how to use them to solve problems. It goes far beyond coding. It includes logic, mathematics, design, data, and creativity.

Programming fundamentals

You begin by learning to think in steps. Variables, loops, conditions, and functions are the building blocks of every program. Python and JavaScript are friendly places to start.

Data structures and algorithms

Lists, stacks, queues, trees, and graphs help you organise information. Algorithms are the recipes that process it quickly and correctly. This is the heart of the degree.

Mathematics for computing

Discrete mathematics, logic, probability, and some linear algebra appear often. They train your mind to reason clearly and prove that a solution works.

Databases and the web

Learn how information is stored, searched, and shared. You will meet SQL, servers, networks, and how websites are built from HTML, CSS, and JavaScript.

Computer systems

Understand what happens inside the machine, from processors and memory to operating systems. It makes you a stronger programmer because you know what your code really does.

How I plan to study

  • Code a little every day, even for twenty minutes.
  • Build small projects, because practice beats reading alone.
  • Learn Git early and save work often.
  • Ask questions and join a study group.
  • Read other people's code to learn new ideas.
  • Rest well. A fresh mind solves bugs faster.

Where it can lead

  • Software and app development
  • Data science and artificial intelligence
  • Cybersecurity
  • Web and user experience design
  • Cloud computing and networks
  • Research, teaching, or starting a company
